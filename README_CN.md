# ComfyUI-XXXXXLCatNodes

<p align="center"><strong>🇨🇳 中文</strong> ·<a href="README.md">🇺🇸 English</a></p>

ComfyUI 扩展，包含八个自定义节点与四项界面功能。

- 节点：清理显存、回收内存、H3 图生视频、任意切换、组控制、节点控制、分辨率选择器、适配尺寸。
- 界面功能：菜单栏系统状态、无限画布、历史画廊侧边栏、多用户文件隔离。

无第三方依赖，不依赖外部服务。界面文案随 ComfyUI 语言设置切换，提供中文与英文。

## 无限画布 🐈‍⬛

菜单栏最左侧的 `Infinite / Canvas` 按钮打开全屏画布，按钮与右侧的清理按钮之间有一条竖分隔符。

画布本体来自上游项目 [ComfyUI-Infinite-Canvas](https://github.com/YangShu2103/ComfyUI-Infinite-Canvas)（MIT © 2026 YangShu2103），以 `infinite_canvas/` 子包形式随本包分发，不再单独安装成第二个 custom node：

- 入口与关闭：点菜单栏按钮打开；`Esc`、点四周遮罩，或左侧栏**最顶部**的「退出画布」关闭（文字与图标暗色白 / 亮色黑，排在「提示词」上方）；栏底是「亮色 / 暗色」主题切换。上游的悬浮圆形按钮及其拖拽位置记忆已移除。
- 画布内布局：顶部是照 ComfyUI 工作流标签做的画布切换条（38px）：**只显示已打开的画布**，非当前标签右侧带 × 可逐个关闭，全部关闭后退化为单个 `Unsaved Canvas`；标签可点击切换、「+」新建，未保存的画布在标签上带圆点，切换前自动保存；`Ctrl/Cmd+S` 可保存（无当前画布时自动新建并保存）。左侧栏照 ComfyUI 的侧栏布局——56px 通高竖栏，每项 19.2px 图标在上、10px 标签在下（尺寸 / 间距 / 位置照 ComfyUI 官方侧栏）；最上方是「退出画布」（暗色白字、亮色黑字），其下是提示词 / 资产库 / 日志，中间一道细线后是画布管理 / 资产管理 / 工作流（这三项点开是居中的弹窗，背景 50% 压暗且其余区域不可点，不像提示词 / 资产库那样贴栏展开），栏底是亮色 / 暗色切换。面板贴栏右侧通高展开。右下角是照 ComfyUI 画布工具栏做的浮动面板：选择 / 拖拽模式、适应视图、缩放控制、网格吸附、隐藏连接线。上游原有的「释放显存」与「聚焦节点」已去掉。提示词 / 资产库 / 任务队列三个面板（以及画布管理、资产管理、工作流配置浮窗）补回了滚动条：上游把所有滚动条都隐藏了，现在按 ComfyUI 的 `.scrollbar-custom` 做成 10px 轨道 + 6px 圆角滑块，暗色用 `--muted`、亮色用 `--border`。侧栏 9 枚图标已统一换成 lucide（SVG 取自 ComfyUI 前端包的 `icon-[lucide--*]`）：退出画布 `log-out`、提示词 `text`、资产库 `image`、日志 `history`、画布管理 `layers`、资产管理 `folder-open`、工作流 `workflow`、主题 `sun`/`moon`；右下工具条本来就是 lucide，未改。**侧栏展开的面板 / 浮动窗口 / 画布管理卡片 / 工作流列表里的 12 枚手写 SVG 也已统一成 lucide**（`x` / `chevrons-left-right` / `shuffle` / `download` / `trash-2` / `copy` / `pencil` / `workflow`），顶部标签栏的实心「+」换成细线 `plus`；全部保留原尺寸，描边改用 `currentColor` 跟随主题。三个贴栏面板（提示词 / 资产库 / 任务队列）的顶部留白按 ComfyUI `SidebarTabTemplate.vue` 补齐：标题区 `min-h-16` 64px 垂直居中、其下内容 `pt-2` 8px（原来标题紧贴顶部标签栏、内容直接压在分隔线上）。标题文字大小照「画廊」/ 官方 Tab 对齐：面板标题 16px/700，资产库分类标签 14px + 32px 高 / 8px 圆角 / 无边框（原来 13px 标题 + 11px 药丸）。三个贴栏面板的边距与间距也对齐画廊 / 官方 4px 网格：水平边距统一 16px（标题 / 胶囊 / 卡片 / 列表 / 页脚左边缘全在 72px），header 内部间距、分类行上下、页脚上下统一 8px，空态 16px、卡片圆角 8px；任务队列列表按日期分组的 `gap:0` 是上游刻意设计，保留。画布节点本体上的功能控件（上传 / 删除节点 / 缩放把手 / 剪线 / 状态 / 对比滑块）不属于侧栏面板，未动。模式按 ComfyUI 的 `read_only` 语义接线：`V` 选择（可编辑，左键拖空白平移、Shift+拖框选）、`H` 拖拽（只读，左键任意位置平移、节点不可选/拖/连），空格按住临时进入拖拽；`Ctrl/Alt+拖` 保留上游的剪线套索。
- 画布管理：弹窗内是**卡片网格**，卡片右上角内联 **复制 / 编辑名称 / 删除** 三个按钮（无右击菜单，头部也无「新建画布」按钮，新建走顶部标签栏「+」）；批量删除仍用列表头的多选 + 「删除所选」。
- 页面与接口：`infinite_canvas/frontend/dist` 的 Vue 3 + Vue Flow 构建产物挂到 `/infinite_canvas/app`，后端接口在 `/infinite_canvas/api/*`。
- 数据：沿用上游位置 `<ComfyUI 用户目录>/ComfyUI-Infinite-Canvas`（画布、工作流、提示词、缩略图），并入前后创建的画布都能直接打开。
- 多用户：上游取的是全局用户目录，`--multi-user` 下各账号共用同一份画布数据，与本包其它功能按账号隔离的做法不同。

## 菜单栏系统状态

ComfyUI 启动后于菜单栏显示状态区，包含五项指标，刷新间隔 0.5 秒。

| 指标 | 区内文字 | 悬停信息 | 填充高度 |
| --- | --- | --- | --- |
| CPU | 占用百分比 | 占用百分比 | 占用比例 |
| RAM | 占用百分比 | 占用百分比、已用/总内存 | 占用比例 |
| GPU | 占用百分比 | 占用百分比、显卡型号 | 占用比例 |
| VRAM | 已用显存（GB） | 占用百分比、已用/总显存、本次会话峰值 | 占用比例 |
| 温度 | 当前温度（°C） | 当前温度、显卡型号 | 40–85 °C 区间内的相对位置 |

温度项的填充色在 40 °C 至 85 °C 区间内由绿向红过渡。未检测到 NVIDIA 显卡时，GPU、VRAM、温度三项显示 `N/A`，CPU 与 RAM 不受影响。

状态区左侧为两个操作按钮，点击后立即执行，无需在画布中添加节点。

| 按钮 | 执行内容 |
| --- | --- |
| RAM Cleanup | 清理系统文件缓存、裁剪各进程工作集、裁剪本进程已加载 DLL，重复 3 次 |
| VRAM Cleanup | 卸载已加载模型、清理 CUDA 缓存 |

两项操作分别等同于「回收内存」「清理显存」节点的预设参数执行。

## 清理显存 🐈‍⬛

卸载已加载模型并释放显存，输出文本报告。

| 输入 | 默认 | 说明 |
| --- | --- | --- |
| 卸载模型 | 开 | 释放前将模型从显存卸载 |
| 清理 CUDA 缓存 | 开 | 释放前清理 CUDA 缓存 |
| 强制 GC | 关 | 额外执行一次垃圾回收与 CUDA 同步 |
| 透传 | — | 可选，原样返回，用于串联执行链 |

| 输出 | 内容 |
| --- | --- |
| 透传 | 原样返回的透传输入 |
| 报告 | 显存释放量，单位 GB |

各步骤相互独立，单个步骤失败不中断其余步骤。

## 回收内存 🐈‍⬛

回收系统内存（非显存），输出文本报告。

| 输入 | 默认 | 说明 |
| --- | --- | --- |
| 清理系统文件缓存 | 开 | 裁剪系统文件缓存，需管理员权限 |
| 裁剪进程工作集 | 开 | 裁剪各进程工作集 |
| 裁剪自身 DLL | 开 | 裁剪本进程已加载 DLL 占用的内存 |
| 重试次数 | 3 | 上述步骤的重复次数 |
| 试运行 | 关 | 仅报告物理内存基线，不执行裁剪 |
| 透传 | — | 可选，原样返回，用于串联执行链 |

| 输出 | 内容 |
| --- | --- |
| 透传 | 原样返回的透传输入 |
| 报告 | 内存回收量（GB）与占用率变化 |

仅 Windows 有效。权限不足时跳过「清理系统文件缓存」，其余步骤继续执行。

## 组控制 🐈‍⬛

以分组为单位切换画布内容。面板位于节点本体内部，每个分组占一行，行内为分组名称与开关。

- 列入范围：画布上所有非空分组，包含完全位于某分组内部的子分组。空分组不列入。
- 关闭一行：将组内全部节点设为「绕过」或「禁用」，由「关闭方式」决定。
- 开关直接改写节点执行模式，与手动绕过、禁用节点等效，不参与采样计算。
- `信号` 为可选透传输入，原样返回，不参与切换。

## 节点控制 🐈‍⬛

使用同一面板，粒度为单个节点。

- 列入范围：画布上所有节点，排除便签、Reroute、PrimitiveNode 及本节点自身。
- 关闭一行：将该节点设为「绕过」或「禁用」。
- 关键词同时匹配节点标题与类型。

## 面板设置（组控制、节点控制共用）

通过节点底部的「⚙ 设置」按钮打开。

| 项 | 选项 | 说明 |
| --- | --- | --- |
| 关闭方式 | 绕过（默认）、禁用 | 关闭一行时对节点执行的操作 |
| 模式 | 自由（默认）、恒定开启一个、最多一个开启、至少一个开启 | 各开关之间的联动规则 |
| 排序 | 名称（默认）、位置、状态、颜色 | 行排序依据 |
| 反向 | 关（默认）、开 | 排序是否逆序 |
| 名称关键词 | 空 | 以 `;` 分隔多个词，命中任一即列入。为空时不列出行，仅显示提示 |
| 颜色筛选 | 无 | 可多选，仅保留所选颜色的对象；节点无自身颜色时继承所属分组颜色 |

面板随画布变更（增删节点、改名、改色）自动刷新。节点宽度可拖动调整，记录于节点属性并随工作流保存。

## H3 图生视频 🐈‍⬛

构建 MiniMax H3 图生视频与文生视频所需的条件输入，一次提供两个阶段的 conditioning 与一个空的音视频潜空间。

| 输入 | 说明 |
| --- | --- |
| CLIP | MiniMax H3 的文本与图像编码器 |
| VAE | 编码关键帧的视频 VAE |
| 提示词 | 文本提示词，参考标签遵循 MiniMax H3 约定 |
| 宽度、高度 | 阶段一的目标尺寸 |
| 长度 | 24 fps 下的帧数，按模型 17k+5 网格对齐 |
| 阶段二宽度、高度 | 阶段二的目标尺寸，关键帧按此尺寸重新编码 |
| 首帧、尾帧 | 可选关键帧 |

| 输出 | 内容 |
| --- | --- |
| 正向条件 | 阶段一采样器使用，按「宽度」「高度」构建 |
| 正向条件2 | 阶段二采样器使用的独立条件对象，按阶段二尺寸构建 |
| 音视频潜空间 | 阶段一使用的空联合潜空间 |

「正向条件2」为按阶段二尺寸单独构建的条件对象，非阶段一的副本，用于在关键帧参与时与放大后的潜空间对齐。

- 未接首尾帧时，「正向条件2」为独立副本，阶段二尺寸不生效。
- 同一输出不可同时接入两个采样器：H3 采样器会就地改写关键帧，两个阶段将相互影响。
- 124 帧约合 5 秒；训练范围为 124–362 帧，更长取值未经验证。

## 任意切换 🐈‍⬛

单路生效的类型无关切换器，用于在多条分支中选择一路继续。

- 端口数从 2 起，每接入一路自动增加一个空位，上限 9 个。
- 首次连线确定类型，其余端口锁定为同一类型；端口标签为「类型_序号」（如 `Latent_01`），输出标签为该类型名称。
- 运行时仅转发携带数据的一路。无输入或多路同时有数据时抛出错误，不静默选择。
- 切换分支在上游完成，下游无需重新连线。

## 分辨率选择器 🐈‍⬛

与官方分辨率节点一致，差异两项。

- 百万像素步进为 0.01，官方为 0.1，可填写两位小数。
- 宽高比新增「自定义」，选中后直接填写宽度与高度；此时「百万像素」隐藏，且不参与计算。

其余行为与官方节点一致：相同宽高比选项、相同分辨率实时预览、相同倍数取整。

## 适配尺寸 🐈‍⬛

按宽高比与百万像素算出目标尺寸，再把图像缩放上去，全程使用单一缩放系数，画面不拉伸。尺寸算法与「分辨率选择器」一致，相同的比例与百万像素值得出相同的结果。

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 宽高比 | 自适应 | 自适应使用输入图片本身的比例；其余为固定比例 |
| 百万像素 | 1.0 | 目标总像素，步进 0.01 |
| 倍数 | 32 | 把算出的尺寸取整到最接近该值的倍数，填 1 表示不取整 |

宽高比选项：自适应、1:1、2:3、3:2、3:4、4:3、9:16、16:9、21:9。

裁切还是补边由节点自行判断，没有开关：

- 目标比例已经贴合图片时（选「自适应」总是如此，固定比例则相差 2% 以内）按覆盖缩放并居中裁掉取整多出的几个像素。不留边框，也不改变构图。
- 相差更大时按放进缩放，居中贴到黑色画布上。保留全部画面，代价是出现黑色边框。

输出：图像、实际产出的宽度与高度、分辨率。分辨率为等效正方形边长 `round(√(宽×高))`，1 MP 的正方形结果为 1024。

节点下方有一行目标尺寸预览，形如 `1376 × 768 1.01 MP`，随宽高比与百万像素的改动实时更新。自适应模式下，预览使用已连接图片的实际宽高；未连接图片时显示破折号。

自适应模式下尺寸仍按倍数取整，产出的比例与图片比例之间存在取整级差异，一般不足 1%。部分比例在网格上没有精确对应，例如 1365×768 在 32 网格上为 1376×768，偏差约 0.8%。此时裁切只削掉边缘几个像素，不改变构图；把倍数改为 1 可得到与原图完全一致的比例，代价是输出尺寸不再与模型的网格对齐。

倍数取整的原因：部分扩散模型（如 Qwen-Image）会在内部按自己的网格重新对齐图像。输出尺寸已落在该网格上时，模型不再缩放，避免二次重采样带来的画面变软。

限制：

- 两种处理都是单一系数缩放，不做拉伸。目标比例与输入比例差异越大，裁切损失的画面越多。
- 补边的填充固定为黑色，不延展画面内容。
- 判定只看比例，不看画面内容：想要强制裁切就选一个贴合画面比例的宽高比，想要强制补边就选一个差得多的。

## 历史画廊

侧边栏标签页，位于「资产」之上。列出当前账号 `output/` 与 `input/` 目录中磁盘上实际存在的全部文件，不限于本次会话产生的文件。

| 区域 | 内容 |
| --- | --- |
| 分页 | 已生成（output）、已导入（input） |
| 类型筛选 | 全部、图片、视频、音频、其他 |
| 工具栏 | 文件名搜索、刷新、视图切换（列表、网格小、网格大） |
| 卡片信息 | 文件名、大小、修改时间 |

选择操作：

- 单击选中，Ctrl 单击加选，Shift 单击连选，空白处拖动框选。
- 选中后底部显示浮动操作条，含选中数量、全部下载、全部删除、取消全选。

右键菜单：

| 项 | 说明 |
| --- | --- |
| 查看资产 | 打开预览层，视频与音频可直接播放，文本显示内容开头；可打开原文件、下载 |
| 作为节点插入到工作流 | 将文件放入 input 目录后在视口中央添加加载节点并填入文件名 |
| 下载 | 下载该文件 |
| 删除 | 将文件移动到系统回收站 |

双击卡片等同于「查看资产」。

限制：

- 删除为移动到系统回收站，可在资源管理器中还原；不支持回收站的位置（如网络驱动器）上仍为直接删除。
- 文件被占用或无删除权限时，文件保留在原处，界面显示删除失败提示。
- 「作为节点插入到工作流」仅对图片、视频、音频可用，3D 模型与其他类型不可用。插入时文件以硬链接放入 input 目录（跨盘时复制），并添加 `LoadImage`、`LoadVideo` 或 `LoadAudio` 节点。
- 将卡片拖入画布使用 ComfyUI 原生拖放，传输对象为原文件。

## 多用户文件隔离

以 `--multi-user` 启动时生效，单用户启动不受影响。

- `input/` 与 `output/` 按账号分为 `input/<用户>/` 与 `output/<用户>/`，各账号的上传与生成文件互不可见。
- 历史、队列、任务列表按账号隔离。
- 登录使用 ComfyUI 原生的用户选择流程，不设密码。
- 全局 `input/`、`output/` 中的既有文件对所有账号不显示。

## 安装

将 `ComfyUI-XXXXXLCatNodes` 文件夹放入 `ComfyUI/custom_nodes/`，重启 ComfyUI。

菜单栏系统状态、历史画廊、多用户文件隔离自动生效，无需在画布中添加节点。

## 环境要求

- Windows。系统状态读取使用 Windows 接口。
- 自带 `comfy_api` 的 ComfyUI 版本（节点基于新版节点接口）。
- 无第三方依赖。

## 卸载

删除 `custom_nodes/ComfyUI-XXXXXLCatNodes/` 文件夹，重启 ComfyUI。
